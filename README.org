* Nexus Novel

A FastAPI backend and a React frontend for reading and managing web novels.
Nexus Novel owns users, libraries, reading progress, downloads and follows.
Story metadata comes from the metadata server ([[https://github.com/finn200102/nexus-server][nexus-server]]).

** Architecture

- *Metadata server.* Each story stores a =metadata_id= that points at a record
  in nexus-server. The backend calls it over HTTP (=METADATA_SERVER_URL=,
  authenticated with =METADATA_API_KEY=) for search, discovery and metadata
  refreshes, and caches what it needs locally.
- *Backend* (=backend/=, Python 3.12+, FastAPI, SQLAlchemy). Serves the REST API
  under the routers in =app/routers/= and runs a background worker
  (=app/worker.py=) that downloads chapters and sends digests. Chapter text is
  stored locally in =DOWNLOAD_PATH=.
- *Frontend* (=frontend/=, React 19, Vite 6, TypeScript, Tailwind). In development
  Vite proxies =/api= to the backend and strips the prefix.

Compose (in the repository root) runs the same pieces as containers: =novel-api=,
=novel-worker=, the frontend behind nginx, and their Postgres database.

** Backend

Requirements: Python 3.12+ and [[https://docs.astral.sh/uv/][uv]].

#+begin_src shell
cd backend
uv sync
#+end_src

Settings come from the environment or =backend/.env=. The useful ones:

| Variable | Default | Meaning |
|---------------------+--------------------------+-----------------------------------------|
| =DATABASE_URL= | =sqlite:///./test.db= | Database connection |
| =DOWNLOAD_PATH= | =./downloads= | Where chapter text is stored |
| =BACKEND_PORT= | =8000= | Port for local runs |
| =METADATA_SERVER_URL= | =http://127.0.0.1:8004= | nexus-server base URL |
| =METADATA_API_KEY= | empty | Key for the metadata server |
| =SECRET_KEY= | placeholder | Replaced by a random key stored in =DOWNLOAD_PATH= when left as a placeholder or empty |

Run the API with auto-reload:

#+begin_src shell
cd backend
uv run uvicorn app.main:app --reload --port 8000
#+end_src

Run the tests:

#+begin_src shell
cd backend
uv run pytest -q
#+end_src

** Frontend

Requirements: Node.js 22 (the version CI uses) and npm.

#+begin_src shell
cd frontend
npm install
npm run dev          # http://localhost:5173, proxies /api to the backend
#+end_src

The proxy target is =VITE_BACKEND_URL= (default =http://127.0.0.1:8000=); the
port is =VITE_FRONTEND_PORT= (default =5173=).

Checks, in the same order CI uses:

#+begin_src shell
cd frontend
npx tsc -b --noEmit
npx eslint src
npx vitest run
#+end_src

End-to-end tests (Playwright) need a running stack; see =package.json=
(=test:e2e=, =test:e2e:docker=).
